# Vector Smooth Studio

Adobe Illustrator의 이미지 추적·단순화·스무스 기능을 참고해 만든 **로컬 실행 웹 앱**입니다.
PNG/JPG/WEBP를 실제 베지어 `path`로 추적하고, 기존 SVG는 앵커를 줄이면서 모서리를 보존해 매끄럽게 다듬습니다.
서버·회원가입 없이 브라우저 안(Web Worker)에서만 처리합니다.

## 실행

```bash
npm install
npm run dev          # http://localhost:5173
# 또는 빌드 후 정적 실행
npm run build && npm run preview
```

- 요구 사항: Node.js 20+ , 최신 Chrome/Edge/Safari/Firefox
- `npm run test:e2e` : 헤드리스 Chrome으로 실제 엔진 테스트(아래 6가지 사례 + 오류 메시지) 실행
  (Chrome 경로가 다르면 `CHROME_PATH=/path/to/chrome npm run test:e2e`)

## 기능

| 영역 | 내용 |
| --- | --- |
| 비트맵 → SVG | 드래그 앤 드롭/파일 선택, 투명도·밝기 기준 전경 판정(자동/밝기/투명도), 반전, 테두리 연결 배경 제거, 임계값, 노이즈 조각 제거(작은 구멍은 별도 보호), 업스케일 보간으로 계단 경계 정리, **Potrace(WASM)** 베지어 추적, 복합 패스(구멍 유지, `fill-rule="nonzero"`), 원본 크기·비율 유지. 결과 SVG에 비트맵을 넣지 않음 |
| SVG 경로 보정 | **Paper.js** 기반. 서브패스별 재샘플링 → 창(window) 기반 꺾임각으로 모서리 검출 후 원본 앵커로 스냅 → 모서리 사이 구간만 가우시안 스무딩(수축 보정) → Schneider 커브 피팅으로 앵커 축소 → 직선 구간은 직선으로. 면적이 20% 넘게 변하거나 노드가 늘면 해당 서브패스는 원본 유지 |
| 안전 처리 | `script`, `foreignObject`, 애니메이션, `on*` 속성, 외부 `href`/`url()`/`@import`, DOCTYPE 엔티티 제거. 텍스트·기본 도형·`image`·클리핑/마스크/패턴 내부 path는 손대지 않고 보존하고 화면에 알림. 그룹·id·`transform`·viewBox 보존(변환 배율을 계산해 허용 오차 보정) |
| 슬라이더 | 스무스 35 / 단순화 20 / 모서리 유지 80 / 노이즈 15 / 곡선 정밀도 85 / 임계값 128. 슬라이더와 숫자 입력 실시간 동기화. 0 = 해당 효과 없음 |
| 비교 뷰 | 2분할·비교선 드래그, 휠 확대(커서 기준), 드래그 이동, 100/200/400/800%, 맞춤, 체크무늬/흰/검정 배경, 경로선·앵커 표시, 노드 수 |
| 분석 | 노드 수(원본→결과, 감소율), 서브패스 수, 형태 차이(래스터 XOR ÷ 원본 면적), IoU, 평균/최대 윤곽 편차 |
| 기록 | 실행 취소/재실행(⌘Z / ⇧⌘Z), 기록 목록에서 임의 시점 이동, 원본 복원, **결과 확정**(현재 결과를 새 기준으로 삼아 이어서 보정, 이전 단계 보관) |
| 다운로드 | SVG / 투명 PNG(1x·2x·4x), 색상 원본·검정·흰색, 미리보기, 파일명 자동(`이름_vector.svg`, `이름_smooth@2x.png`) |
| 프리셋 | 원본 최대 보존, 자연스러운 스무스, 강력한 선 정리, 로고 및 타이포그래피, 날카로운 스트릿 그래픽, 스티커 인쇄용 |

UI 정규화 값 → 엔진 매개변수 변환 기준은 [`src/engine/params.ts`](src/engine/params.ts)의 주석에 정리되어 있습니다.
핵심 원칙: 스무스를 올려도 **모서리 유지 값이 판정한 모서리는 둥글게 만들지 않습니다**(스무딩은 모서리 사이 구간에만 적용, Potrace `alphamax` 상한도 모서리 유지 값이 결정).

## 구조

```
src/engine/params.ts    UI 값 ↔ 엔진 매개변수 변환, 프리셋
src/engine/trace.ts     비트맵 → 마스크 → Potrace → path (Worker)
src/engine/refine.ts    SVG path 보정 알고리즘 (Worker, Paper.js)
src/engine/svgDoc.ts    SVG 정화·분석·재조립 (메인 스레드)
src/engine/pipeline.ts  처리 + 형태 차이 측정 (UI·테스트 공용)
src/components/         뷰어, 슬라이더, 다운로드 대화상자
tests/harness.ts        브라우저 엔진 테스트, tests/fixtures/ 테스트 이미지
```

## 테스트 사례 (npm run test:e2e)

1. 투명 배경 검정 PNG 로고 — 형태 차이, 링 구멍, 사각 모서리·별 끝 위치
2. 계단 현상이 심한 48×48 PNG — 이상적 원 대비 편차, 모서리, 노드 수
3. 노드가 과도한 SVG(1,800개 곡선 노드 + transform 그룹 + 텍스트/도형/스크립트/외부 이미지) — 노드 감소, 보존, 차단, 슬라이더 0 무변경
4. 구멍 글자 O·B·8 — PNG 추적과 복합 경로 SVG 보정 모두 구멍 5개 유지
5. 뾰족한 7각 별 + 붓 획 — 끝점 위치(프리셋별), 지터 별 SVG를 스무스 100으로 보정해도 끝 유지
6. 흰색 로고 + 투명 배경 — 자동 투명도 판정, 흰색 유지, 구멍
7. 오류 메시지 — 깨진 SVG/비SVG/깨진 PNG/빈 이미지

각 사례에서 SVG(원본·검정·흰색) 파싱 유효성, 비트맵 미포함, PNG 1x/2x/4x 크기를 확인합니다.

## 제한 사항

- 비트맵 추적은 **단색(1색) 추적**입니다. 결과 색은 전경 평균색이며, 다색 분리 추적은 지원하지 않습니다.
- 매우 예리한(약 20° 이하) 끝은 원본 래스터 자체에 정보가 없어 1~3px 짧아질 수 있습니다.
- SVG 보정은 `<path>`만 대상입니다. 기본 도형·텍스트는 의도적으로 변경하지 않으며, 클리핑·마스크·패턴 내부 path도 보존합니다.
- 비균일 스케일/기울임 transform 아래의 path는 면적 배율로 허용 오차를 근사합니다.
- 처리 한도: 파일 50MB, 비트맵 한 변 20,000px(1,600만 픽셀 초과 시 축소 처리 후 원본 좌표로 복원), 추적 작업 해상도 800만 픽셀, SVG 20MB.
- Potrace(`esm-potrace-wasm`)는 **GPL-2.0** 라이선스입니다. 이 앱을 배포할 경우 GPL 조건을 확인해 주세요.
